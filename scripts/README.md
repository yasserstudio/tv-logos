# Scripts Directory

This directory contains utility scripts for managing the TV Logos repository.

## Available Scripts

### validate.js (Coming Soon)
Validates logo files for:
- Correct naming convention
- File format (PNG)
- Dimensions (512px width)
- File size (< 100KB)

### update-index.js (Coming Soon)
Automatically updates `index.json` with new logos added to the repository.

### optimize.js (Coming Soon)
Batch optimizes PNG files for web usage.

## Usage

Scripts will be added as the repository grows and automation needs arise.

## Requirements

- Node.js 16+
- npm or yarn
